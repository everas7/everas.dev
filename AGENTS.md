# Agent rules

Personal blog at https://everas.dev. Next.js 13 (app router), Contentlayer, Tailwind and Pliny,
based on `tailwind-nextjs-starter-blog`. Pushing to `main` deploys to Vercel.

## Commands

Use Node 24 and Yarn 3.6.1 (bundled in `.yarn/releases`). Don't use npm.

- install: `yarn install`
- dev: `yarn dev`
- build: `yarn build` (Next.js build, then RSS generation)
- serve a build: `yarn serve` (`yarn start` runs the dev server)
- lint, check only: `yarn next lint --dir app --dir components --dir layouts --dir scripts`
- lint with fixes: `yarn lint` (rewrites files)
- type check: `yarn tsc --noEmit --tsBuildInfoFile node_modules/.cache/tsconfig.tsbuildinfo`
  (run a build first so `.contentlayer/generated` exists)
- test: there is no test suite. Verify with lint, type check and build.

## Layout

- `data/blog/*.mdx` posts · `data/authors/*.mdx` authors
- `data/siteMetadata.js` site config · `data/headerNavLinks.ts` navigation
- `app/` routes · `layouts/` post, list and author layouts · `components/` shared UI
- `contentlayer.config.ts` content schema, MDX plugins and tag counts
- `scripts/` postbuild and RSS · `css/` Tailwind and Prism styles
- Import aliases: `@/components/*`, `@/data/*`, `@/layouts/*`, `css/*`

## Writing posts

- Required frontmatter: `title`, `date`. Usual: `lastmod`, `tags`, `draft`, `summary`, `layout`.
- `layout` is `PostLayout` (default), `PostSimple` or `PostBanner`. Current posts use `PostSimple`.
- `authors` defaults to `default`, which is `data/authors/default.mdx`.
- The filename becomes the URL slug.

## Gotchas

- `app/tag-data.json` is generated by the build but tracked. Commit it when tags change.
- `public/feed.xml` is generated and ignored. Don't edit it.
- Adding an external script, font, frame or media host means updating the Content Security Policy
  in `next.config.js`.
- `@contentlayer/core` carries a Yarn patch for Node 24 (`.yarn/patches/`). Contentlayer is
  unmaintained. Never edit `node_modules` directly: use `yarn patch`, then `yarn patch-commit -s`,
  and commit the patch file.
- Keep `engines.node` in `package.json` on a version Vercel supports. It overrides the Vercel
  project setting.
- The Husky pre-commit hook is not installed by `yarn install`, so run lint yourself.
- `data/authors/sparrowhawk.mdx` is still starter template content.
- The repository is public. Never commit secrets. Environment variable names are in `.env.example`.
