# E1-S1 Profile Hero + E2E Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the blog-style `/` with a profile hero (name, role, intro and four tracked links) and add the Playwright e2e harness.

**Architecture:** `data/profile.ts` holds the spec's Content as typed constants. `app/Main.tsx` renders the hero from it, with no Contentlayer data. Playwright runs Chromium against a production build served by `yarn serve`.

**Tech Stack:** Next.js 13.4 app router, Tailwind 3, Yarn 3.6.1 (node-modules linker), Node 24, `@playwright/test` (current stable).

**Spec:** `docs/superpowers/specs/2026-11-26-e1-s1-home-hero-design.md`. Also read `docs/product/features/portfolio-home/spec.md` ("Content", FR-1/2/3/8/15) and `ux.md` ("Home" 1, "Umami events").

- Link labels, in order: `Résumé (PDF) →`, `Email`, `GitHub`, `LinkedIn`.

  - `https://www.linkedin.com/in/everas7/`
- Umami: `data-umami-event` = `resume` | `email` | `github` | `linkedin`, plus `data-umami-event-where="home"`.
- Token → class (from the current `app/Main.tsx`, DESIGN.md):
  - display chain `h1`: `text-3xl font-extrabold leading-9 tracking-tight text-gray-900 dark:text-gray-100 sm:text-4xl sm:leading-10 md:text-6xl md:leading-14`

- Story done = `yarn build && yarn test:e2e e2e/home-hero.spec.ts` passes, plus lint and type check (AGENTS.md).

## Review Focus

1. **400px link row:** the four links wrap with no horizontal page scroll. Test: `scrollWidth <= 400` (Task 2).
2. **Email link:** must not open a blank tab. Test: no `target` attribute on the mailto link (Task 2).
3. **Résumé tab safety:** it opens in a new tab without exposing `window.opener`. Test: `target="_blank"`, `rel` contains `noopener` (Task 2).
4. **Console errors on load:** the page loads with no console errors (CSP or hydration). Test: collect `console` errors on `/`, expect none (Task 2).
5. **Dark theme render:** the hero renders under `prefers-color-scheme: dark` without layout change. This is covered by FR-1's dark run (Task 2).
