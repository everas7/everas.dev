# E1-S6 Site metadata, titles and RSS links Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Titles and link previews describe the professional profile, and no page advertises the RSS feed.

**Architecture:** `data/siteMetadata.js` holds the home title and description; `author` supplies the title suffix and preview site name. `app/layout.tsx` and `app/seo.tsx` read them. RSS generation is untouched.

**Tech Stack:** Next.js 13.4 app router metadata, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-26-e1-s6-metadata-design.md`

## Global Constraints

- Home `<title>` and Open Graph title: "Enmanuel Veras – Senior Software Engineer" (en dash).
- Other pages: "%s | Enmanuel Veras".
- Description: `profile.intro` word for word, copied into `data/siteMetadata.js`.
- Open Graph site name: "Enmanuel Veras". Header logo text: "everas.dev".
- `scripts/rss.mjs`, `siteLogo`, `socialBanner`, `app/sitemap.ts` and `robots` metadata don't change.
- No new dependency. No visible change to any page.
- Titles in the spec file are written out; only the description is compared with `profile.intro`.
- Before each commit: `yarn build`, then `yarn next lint --dir app --dir components --dir layouts --dir scripts` and `yarn tsc --noEmit --tsBuildInfoFile node_modules/.cache/tsconfig.tsbuildinfo` pass.
- Run tests as `APP_PORT=3106 yarn test:e2e …`. Tests run against the last build, so build first.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Navigating inside the app (Home → About → Home): the tab title follows the page (Task 1).
2. A paginated blog URL: it gets the "Blog" title, not the home title (Task 1).
3. A shared post link: the preview keeps the post's own title, with the new site name (Task 1).
4. A tag page without its own `alternates`: it keeps its own canonical URL (Task 2).
5. Existing RSS subscribers: both feed URLs still answer, with the new channel title (Task 2).

```ts
import { test, expect, type Page } from '@playwright/test'
import { profile } from '../data/profile'

const HOME_TITLE = 'Enmanuel Veras – Senior Software Engineer'
const NAME = 'Enmanuel Veras'
const POST = '/blog/taking-ownership'
const POST_TITLE = 'Taking Ownership as a Developer'

const meta = (page: Page, key: string) =>
  page.locator(`head meta[name="${key}"], head meta[property="${key}"]`)

async function expectTitles(page: Page, title: string) {
  await expect(page).toHaveTitle(title)
  await expect(meta(page, 'og:title')).toHaveAttribute('content', title)
  await expect(meta(page, 'twitter:title')).toHaveAttribute('content', title)
  await expect(meta(page, 'og:site_name')).toHaveAttribute('content', NAME)
}

test('FR-10 home title and description', async ({ page }) => {
  await page.goto('/')
  await expectTitles(page, HOME_TITLE)
  await expect(meta(page, 'description')).toHaveAttribute('content', profile.intro)
  await expect(meta(page, 'og:description')).toHaveAttribute('content', profile.intro)
})

for (const [path, title] of [
  ['/about', 'About'],
  ['/blog', 'Blog'],
  ['/blog/page/1', 'Blog'],
  ['/tags', 'Tags'],
  ['/tags/react', 'react'],
]) {
  test(`FR-10 ${path} follows the title template`, async ({ page }) => {
    await page.goto(path)
    await expectTitles(page, `${title} | ${NAME}`)
    await expect(meta(page, 'description')).toHaveAttribute('content', profile.intro)
  })
}

test('FR-10 a post keeps its own preview title', async ({ page }) => {
  await page.goto(POST)
  await expect(page).toHaveTitle(`${POST_TITLE} | ${NAME}`)
  await expect(meta(page, 'og:title')).toHaveAttribute('content', POST_TITLE)
  await expect(meta(page, 'twitter:title')).toHaveAttribute('content', POST_TITLE)
  await expect(meta(page, 'og:site_name')).toHaveAttribute('content', NAME)
})

test('FR-10 tag description keeps the site name', async ({ page }) => {
  await page.goto('/tags/react')
  await expect(meta(page, 'og:description')).toHaveAttribute(
    'content',
    'everas.dev react tagged content'
  )
})

test('FR-10 header logo text stays', async ({ page }) => {
  await page.goto('/')
  await expect(page.locator('header').getByText('everas.dev', { exact: true })).toBeVisible()
})

test('FR-10 title follows in-app navigation', async ({ page }) => {
  await page.goto('/')
  await page.locator('header').getByRole('link', { name: 'About', exact: true }).first().click()
  await expect(page).toHaveTitle(`About | ${NAME}`)
  await page.locator('header').getByRole('link', { name: 'everas.dev' }).click()
  await expect(page).toHaveTitle(HOME_TITLE)
})
```
